SensorBees Hub Ecosystem

Industrial-grade IoT sensor solutions — from field to cloud

SensorBees Hub offers a comprehensive suite of LoRaWAN IoT solutions for digitalizing the world around us. From sensors to gateways, from edge to cloud — we help you monitor, collect, and analyze environmental data in real-time.

Wild IoT — Sense the World

Wild IoT refers to deploying sensor networks in natural environments to monitor and collect various environmental data in real-time. This includes temperature, humidity, air pressure, light intensity, soil moisture, and more.

Quick Start Guide

1. Set up Gateway

Connect your LPS8N gateway to power and network. Access the web UI to configure LoRaWAN frequency plan (CN470).

2. Deploy ChirpStack

Install ChirpStack v4 via Docker. Configure the network server and add your gateway.

3. Register Sensors

Add your sensor devices in ChirpStack with the correct AppEUI, DevEUI, and AppKey.

4. Monitor Data

View real-time sensor data, set up integrations, and build your dashboards.
