Quick Setup Steps

1. Deploy Gateway

Install LPS8N (indoor) or DLOS8 (outdoor) gateway, connect to network via Ethernet/WiFi/4G. Configure frequency plan (CN470 for China).

2. Set Up ChirpStack

Deploy ChirpStack v4 via Docker. Add gateway, create application and device profiles.

3. Register Devices

Add sensor devices in ChirpStack with correct AppEUI, DevEUI, and AppKey (OTAA) or ABP credentials.

4. Integrate & Visualize

Set up MQTT/HTTP integration to forward data to your dashboard, database, or business system.

Cellular (4G/NB-IoT) is ideal when LoRaWAN gateway deployment isn't feasible — remote sites, mobile assets, or scenarios requiring direct cloud connectivity without local infrastructure.

❓Frequently Asked Questions

Q What frequency band should I use? +

For China, use CN470. For Europe, use EU868. For North America, use US915. Make sure your gateway and sensors are configured to the same frequency plan. All SpringBees sensors support common LoRaWAN frequency bands.

Q How long does the sensor battery last? +

Battery life depends on reporting interval. At 1 report per 5 minutes, most SpringBees sensors last 2~5 years. Increasing the interval to 15 minutes can extend life to 5~10 years. RS485 sensors require external power.

Q What is the wireless range of LoRaWAN? +

Line-of-sight: up to 15km with outdoor gateway (DLOS8). Urban: 2~5km with indoor gateway (LPS8N). Indoor: 500m~1km through walls. Range depends on antenna, elevation, and obstacles.

Q Can I use my own cloud platform? +

Yes. ChirpStack supports MQTT and HTTP integrations to forward data to any platform — AWS IoT, Azure, ThingsBoard, Grafana, or your custom backend. Data format is standard JSON via MQTT topics.

Q How do RS485 sensors connect wirelessly? +

RS485 sensors connect to a LoRaWAN RS485 node (like Dragino LSN50v2) via Modbus RTU. The node reads sensor data periodically and transmits via LoRaWAN to the gateway. Up to 8 RS485 sensors can share one node with different Modbus addresses.

Q LoRaWAN vs Cellular — which should I choose? +

Choose LoRaWAN when: you have many sensors in a concentrated area, need long battery life, and can deploy a gateway.
Choose Cellular when: you have few sensors in remote locations, no gateway infrastructure is available, or you need quick standalone deployment.

Q How do I register a sensor on ChirpStack? +

In ChirpStack: go to your Application → Devices → Add. Enter DevEUI, AppEUI, and AppKey from the sensor label. Select the correct Device Profile (OTAA recommended). Power on the sensor — it should join within 1~2 minutes and start reporting data.
