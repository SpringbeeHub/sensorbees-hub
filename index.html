🌐Build Your Wireless Network

LoRaWAN is ideal for large-scale sensor deployments over wide areas (up to 15km line-of-sight). Ultra low power consumption enables years of battery life for field sensors.

Quick Setup Steps

1. Deploy Gateway

Install LPS8N (indoor) or DLOS8 (outdoor) gateway, connect to network via Ethernet/WiFi/4G. Configure frequency plan (CN470 for China).

2. Set Up ChirpStack

Deploy ChirpStack v4 via Docker. Add gateway, create application and device profiles.

3. Register Devices

Add sensor devices in ChirpStack with correct AppEUI, DevEUI, and AppKey (OTAA) or ABP credentials.

4. Integrate & Visualize

Set up MQTT/HTTP integration to forward data to your dashboard, database, or business system.

Cellular (CAT-1/CAT-M/NB-IoT) is ideal when LoRaWAN gateway deployment isn't feasible — remote sites, mobile assets, or scenarios requiring direct cloud connectivity without local infrastructure.
